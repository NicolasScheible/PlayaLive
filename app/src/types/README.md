# types/

Geteilte TypeScript-Typen für die Domänenbegriffe aus `docs/Database.md` (`Location`, `Artist`,
`Event`, `Report`, `Review`, `Favorite`, `Notification` u. a.). Benennung ohne `I`-Präfix, konsistent
zu den in `docs/Database.md`/`docs/API.md` verwendeten Fachbegriffen (siehe `CLAUDE.md` →
Namenskonventionen).
