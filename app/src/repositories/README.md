# repositories/

Repository-Schicht für Services mit komplexer Business-Logik (siehe `docs/Architecture.md` Kapitel 9
„Repository Pattern" und `docs/ADR/005-API-Architecture.md`) — pragmatisch, nicht pauschal für jeden
Service. Wird erst befüllt, sobald der jeweilige Service (`ReportService`, `ReviewService`,
Trust-Score-Berechnung, Community-Aggregation) implementiert wird.
